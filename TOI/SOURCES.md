# 來源與整理方式

[官方題目索引](https://tpmso.k12ea.gov.tw/toi/index.php/tasks/)於 2026-10-16 讀取，334 個題目列全部納入 manifest。

各題條目保留題目、參考程式與詳解投影片網址。ZIP 檔另記 SHA-256，便於核對下載來源版本。官方參考 C++ 轉為 UTF-8、正規化換行，並加入標準標頭與出處註解；2023-12 同好會「間諜」另將不能初始化的變長陣列改為等價的零初始化 vector<array<int,26>>，修正編譯錯誤。自行重寫的版本在 cpp_origin 標為 authored，使用獨立演算法實作。Python 版本與獨立詳解由本次整理撰寫，依官方題意與參考資料核對。

每份說明皆連回官方題目與詳解。官方程式、題目與投影片的權利仍歸原作者；此處不替第三方資料追加授權，也沒有移除原有署名。未將完整題目或投影片文字複製到 Markdown。

tests/samples.json 保存已完成雙語題目的官方範例，僅用於重現程式驗證。範例從 PDF 擷取後實際跑過兩種語言；測試按空白分詞比較，不比較行尾空白。沒有使用或宣稱擁有官方隱藏測資。
