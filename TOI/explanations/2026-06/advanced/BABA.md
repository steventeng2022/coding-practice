# 3-BABA

以下思路、正確性與複雜度以本儲存庫的 Python 版為主；C++ 檔是官方參考實作，其資料結構與常數可能不同，並未逐題證明為最快。

## 解題思路

每種字母最多連續 K 次。若某字母有 x 個，其他字母共 y 個，最多能分隔出 y+1 段，所以必須有 x≤K(y+1)。逐位按 C、B、A 嘗試，只有在剩餘數量仍能排完時才接受，以取得字典序最大字串。檢查剩餘數量時，尾端同字母那一段已使用的長度也要扣除。

## 正確性

若最多的字母數量超過所有可用區塊容量，就一定無解；反之可用其他字母作分隔，將最多字母分成不超過 K 的區塊。固定目前尾端後，同字母首段容量縮短，其餘字母仍有完整首段容量。每次挑選仍有可行後綴的最大字母，不會犧牲可行性，並且第一次與任何其他可行答案不同時必較大，因此得到字典序最大解。

## 複雜度

令 L=A+B+C，時間 O(L)，空間 O(L)（輸出字串）；每步最多嘗試三種字母並檢查三個容量。

## 實作注意

C++ 的負數整除與 Python // 不同；本版改用乘法不等式避免此差異。恰好 K 個相同字母仍合法。
